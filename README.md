# Check-In

An Android only app that helps ensure the safety of people that are living alone.,br>
The App rings an alarm according to a user set schedule, and if the user fails to turn-off the alarm, the device notifies a designated group of contacts that the user is not 'checking-in' on schedule. Includes the GPS location of the device.<br>
This can be useful if the user suffers a fall, or stroke or any other event that prevents him/her from asking for help.<br>
Additionally there is an 'Emergency' button that send an SMS message with the GPS location on command.<br>
This app is written entirely by an AI system, according to a design porovided by the programmer.<br>
