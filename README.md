# Check-In

An Android only app that helps ensure the safety of people that are living alone.

The App rings an alarm according to a user set schedule, and if the user fails to turn-off the alarm, the device notifies a designated group of contacts via SMS that the user is not 'checking-in' on schedule. Includes the GPS location of the device.

This can be useful if the user suffers a fall, or stroke or any other event that prevents him/her from asking for help.

Additionally there is an 'Emergency' button that send an SMS message with the GPS location on command.

This app is written entirely by an AI system, according to a design provided by the programmer.

### Features

* Set up to 5 alarm times.Alarm will ring for 1 minute.
  * If the alarm is not manually stopped, the alarm will wait 5 minutes and try again.
* Manual check-in at any time.
